# PDF.ATHAT Desktop

تطبيق مستقل لقراءة ملفات PDF والكتابة بالقلم والتظليل وإضافة التعليقات والتوقيع فوق الصفحات مثل الكتاب الورقي. **لا يغيّر الملف الأصلي**؛ تُحفظ الإضافات محليًا في قاعدة منفصلة، ويمكن تنزيل الأصل كما هو أو تصدير نسخة PDF مشروحة.

## التشغيل دون إنترنت

يضم التطبيق محرك PDF.js وpdf-lib وملفات الخطوط والـWASM في حزمة التثبيت. بعد التثبيت لا يلزم الاتصال بالشبكة للقراءة والكتابة والتصدير. يستخدم خادمًا داخليًا على عنوان `127.0.0.1:41753` فقط لعرض الواجهة؛ **لا يعني ذلك اتصالًا بالإنترنت**. تحفظ المكتبة والكتابات محليًا في بيانات التطبيق داخل حساب نظام التشغيل.

## تنزيل نسخة سطح المكتب

1. افتح [صفحة بناء التطبيق](https://github.com/mrabdulmohsinalotaibi-beep/pdf-athat/actions/workflows/desktop.yml).
2. افتح أحدث تشغيل ناجح واجتز فيه اختبار Electron، ثم نزّل Artifact المناسب: `pdf-athat-windows-latest` أو `pdf-athat-macos-latest` أو `pdf-athat-ubuntu-latest`.
3. فك ضغط Artifact؛ اختر الملف المناسب لنظامك:
   - Windows: ملف تثبيت `.exe` أو نسخة Portable.
   - macOS: ملف `.dmg`.
   - Linux: ملف `.AppImage` (قد يلزم منحه صلاحية التنفيذ).
4. تحقّق من بصمات `SHA256SUMS.txt` الموجودة مع حزمة نظامك إذا رغبت.

ملفات التثبيت **غير موقعة رقميًا**؛ قد تظهر تحذيرات Windows SmartScreen أو macOS Gatekeeper. لا يُنصح بتجاوز تحذير ملف من مصدر غير موثوق. الإصدارات المنشورة بعلامة `v*` تُنشأ كإصدارات تجريبية بعد اجتياز اختبارات البناء.

## النسخ الاحتياطي

في مكتبة المستندات اختر **نسخة احتياطية**؛ ستحصل على ملف `.athatbackup` يحتوي على ملفات PDF الأصلية والكتابات والتعليقات. وللاستعادة اختر **استعادة نسخة** ثم حدّد الملف. الإصدارات الجديدة من النسخ الاحتياطية (الإصدار 2) تتطلب بصمة SHA-256 لكل PDF. الاستعادة لا تستبدل مستنداتك الحالية؛ تنشئ نسخًا مستقلة وتربط بها التعليقات ضمن معاملة قاعدة بيانات واحدة. النسخ الاحتياطية **غير مشفرة**؛ خزّنها في مكان آمن.

بيانات تطبيق سطح المكتب مستقلة عن بيانات الموقع في المتصفح، ولا تنتقل تلقائيًا. انقل ملفاتك المهمة يدويًا أو عبر النسخة الاحتياطية المناسبة.

## البناء والاختبارات

يتطلب Node.js 22 وnpm، ويجب تثبيت الاعتماديات في المرة الأولى عبر الإنترنت:

```bash
cd desktop
npm install
npm run test:offline
npm run start
```

على Linux يمكن تشغيل اختبار واجهة Electron تحت Xvfb:

```bash
xvfb-run -a npm run test:electron
```

يتضمن اختبار Electron فتح PDF بصفحتين، رسمًا بالقلم، التراجع والإعادة، حفظ نسخة الأصل ومقارنة SHA-256، تصدير نسخة مشروحة، النسخ الاحتياطي والاستعادة ورفض ملف تم العبث به، ثم إعادة تشغيل التطبيق والتحقق من استمرار البيانات.

التعبئة: `npm run dist:win` أو `npm run dist:mac` أو `npm run dist:linux` من النظام الموافق. GitHub Actions ينفذ الاختبارات ويبني الحزم للأنظمة الثلاثة.

## القيود الحالية

- التعديل هو طبقة كتابة فوق PDF، **لا يغيّر نصوص المستند الداخلية أو تنسيقه الأصلي**.
- البحث النصي يحتاج PDF نصيًا؛ لا يتوفر OCR للمستندات المصورة.
- بعض المستندات المحمية أو ذات الترميز غير المعتاد قد لا تُعرض أو تُصدّر بدقة.
- ينبغي اختبار حجم الكتابة العربية وتوافق القلم وحفظ الملاحظات على الجهاز المستهدف قبل اعتماد إصدار مستقر.
- لا توجد مزامنة سحابية تلقائية؛ النسخ الاحتياطية مسؤولية المستخدم.
