# PDF.ATHAT Desktop

تطبيق لقراءة ملفات PDF والكتابة على صفحاتها مثل الكتاب الورقي. يظل ملف PDF الأصلي دون تعديل، وتُخزن الكتابة في طبقة تعليقات مستقلة ضمن بيانات التطبيق. يمكن إخفاؤها وعرضها وتنزيل الأصل أو نسخة مشروحة.

البرنامج يحزم محرك PDF.js وpdf-lib ومساعدات الخطوط محليًا ليعمل بعد التثبيت بلا إنترنت. تخزين التطبيق منفصل عن بيانات الموقع داخل المتصفح.

## تحميل نسخة Windows

افتح GitHub > Actions > Build PDF.ATHAT Desktop > آخر تشغيل ناجح > Artifacts ثم نزل pdf-athat-windows-latest. قد تظهر رسالة من Windows لأن الملف غير موقع رقميًا. تتوفر حزم Linux وmacOS أيضًا.

## تجربة المطور

Node.js 22:
```bash
cd desktop
npm install
npm run start
npm run dist:win
```

**اختبارات مطلوبة قبل الاعتماد:** فتح ملف عربي دون إنترنت، قلم وتظليل، إخفاء وإظهار، إغلاق وإعادة فتح، تنزيل الأصل ومقارنة SHA-256، تنزيل نسخة مع الشروح، ملفات كبيرة ومحمية. لم تجر اختبارات التشغيل الفعلية بعد.

## حدود النسخة

تتيح أدوات المشروع الحالية؛ لا تدعم تعديل النص الداخلي الأصلي أو OCR. يوصى بنسخ احتياطي للمستندات المهمة.
