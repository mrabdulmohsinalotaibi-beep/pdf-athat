# PDF.ATHAT — قارئ ودفتر PDF بالعربية

موقع وتطبيق سطح مكتب لفتح ملفات PDF والقراءة والكتابة اليدوية فوق الصفحات **مع المحافظة على الملف الأصلي دون أي تغيير**. تحفظ الملاحظات والرسم في طبقة مستقلة؛ ويمكن إخفاؤها أو إظهارها، وتنزيل PDF الأصلي أو نسخة جديدة بالشروح.

## الموقع

- الموقع: https://pdf.athat.app
- بعد بناء المشروع والنشر عبر Cloudflare Pages، تُحمّل مكتبات PDF.js وpdf-lib من ملفات الموقع نفسه بدل CDN خارجي.
- تخزّن PWA ملفات الواجهة محليًا، لكن فتح الموقع والتحقق من الحساب يتطلبان اتصالًا. بعد الدخول يمكن مواصلة القراءة محليًا أثناء الجلسة المفتوحة؛ إعادة التحقق تحتاج اتصالًا. تطبيق سطح المكتب هو النسخة المخصصة للاستخدام دون إنترنت.
- نسخة الموقع المبنية تتطلب حسابًا بالإيميل وكلمة المرور وتأكيد ملكية البريد. إعدادها موضح في [AUTH_SETUP.md](AUTH_SETUP.md). لا ترفع ملفات PDF إلى الخادم ولا توفر مزامنة سحابية. تطبيق سطح المكتب يبقى دون تسجيل.
- تحفظ ملفات PDF والملاحظات في IndexedDB ضمن مساحة هذا الموقع على الجهاز. ليست مجلدًا ظاهرًا في تطبيق الملفات؛ قد يمسح المتصفح هذه المساحة عند حذف بيانات الموقع أو عند نقص التخزين، لذا استخدم النسخ الاحتياطية بانتظام.
- لتشغيل نسخة التطوير دون بناء يمكن استخدام خادم HTTP محلي، لكنها قد تعتمد على CDN؛ **البناء الإنتاجي هو النسخة المخصصة للعمل دون اتصال**.

## تطبيق سطح المكتب

تفاصيل البناء والاختبارات والنسخ الاحتياطي في [desktop/README.md](desktop/README.md).

- [بناء Windows وmacOS وLinux من GitHub Actions](https://github.com/mrabdulmohsinalotaibi-beep/pdf-athat/actions/workflows/desktop.yml)
- تُضمّن محركات PDF وملفات الخطوط في حزمة التطبيق للعمل دون إنترنت بعد التثبيت.
- ملف PDF الأصلي يبقى دون تعديل؛ نسخة الشروح ملف منفصل.
- البيانات في الموقع منفصلة عن بيانات تطبيق سطح المكتب ولا تنتقل تلقائيًا؛ يمكن استعمال ملفات النسخ الاحتياطي والنقل اليدوي.

## إنتاج نسخة موقع PWA

في Cloudflare Pages يستعمل المشروع الأمر:

```bash
cd desktop && npm install --ignore-scripts --no-audit --no-fund && npm run build:offline && node scripts/build-site.cjs
```

مجلد الإخراج: `desktop/dist`.

لتجربة بناء الموقع محليًا:

```bash
cd desktop
npm install
npm run build:offline
node scripts/build-site.cjs
```

## حدود مهمة

- التحرير طبقة إضافات فوق PDF وليس تعديلًا للنص الأصلي.
- النص العربي في بعض ملفات PDF القديمة قد لا يظهر بشكل مثالي إذا لم تتضمن خطوطًا سليمة.
- البحث في الملفات المصورة يحتاج OCR، وهي ميزة غير متوفرة حاليًا.
- النسخ الاحتياطية غير مشفرة؛ احفظها بعيدًا عن أي أشخاص غير مخولين بالاطلاع على ملفاتك.
- لا تعد اختبارات الشيفرة بديلًا عن تجربة تثبيت التطبيق واستخدام قلم فعلي على الأجهزة المستهدفة.
