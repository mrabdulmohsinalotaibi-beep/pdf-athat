# PDF.ATHAT

منصة عربية مستقلة لقراءة ملفات PDF، والرسم والتظليل الحر عليها، والتصدير إلى PDF، دون رفع المستندات تلقائيًا.

## المنجز حاليًا

- عرض PDF والتنقل والتكبير باستخدام PDF.js.
- قلم وتظليل حر فوق الصفحات (التظليل الحر ليس تحديدًا للنص).
- حفظ المستندات والتعليقات داخل IndexedDB على جهاز المستخدم.
- تصدير نسخة PDF تتضمن خطوط القلم والتظليل بواسطة pdf-lib.
- إدارة مكتبة ملفات بسيطة وحذف المستند وتعليقاته.
- واجهة عربية متجاوبة، وملف Web App Manifest.

## التشغيل

المشروع حاليًا **موقع ثابت بدون خطوة بناء**. شغّل الملفات من خادم HTTP محلي أو انشرها كأصول ثابتة. لا تفتح index.html عبر file://. مثال:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

يصلح للمواقع الثابتة على Cloudflare Pages مع إعداد build command فارغ ومجلد إخراج المشروع `/` بعد تهيئة الربط بمستودع GitHub. **لم يُنشر على pdf.athat.app بعد**.

## قيود النسخة التجريبية

- تستورد المكتبات من jsDelivr، وبالتالي يتطلب بدء تشغيل القارئ اتصالًا بالشبكة؛ العمل الكامل دون اتصال يحتاج حزمًا محلية وService Worker.
- التحرير الحر عبارة عن خطوط فوق الصفحات، ولا يدعم حتى الآن تعديل النص الأصلي أو البحث أو تحديد النص أو OCR.
- التخزين المحلي قد يُمحى عند إزالة بيانات الموقع، لذا نزّل النسخ المهمة على الجهاز.
- بعض ملفات PDF المحمية أو الكبيرة قد لا تفتح أو تُصدّر.
- لا توجد حسابات أو مزامنة أو تكامل مع الذات في هذا الإصدار.
- يلزم اختبار يدوي على متصفحات الهاتف والتابلت قبل الإطلاق العام.

## الأمان

لا تحفظ مستندات تحتوي بيانات شخصية حساسة حتى اكتمال فحص الأمان واختبارات التخزين والتصدير. يفضّل تفعيل قيود أمن المحتوى لاحقًا وتقليل الاعتماد على CDN خارجي.

## Cloudflare Pages

تم ربط المستودع بمشروع Cloudflare Pages مستقل باسم `pdf-athat`، والنشر التلقائي من `main`.
